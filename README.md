# Paper Search releases

Paper Search adds local PDF library search to Codex through MCP. Download the
archive for your operating system and architecture from the [Releases page](../../releases).

Extract the archive and follow `README.txt` for manual setup or open the
extracted folder in a local Codex chat and ask it to follow `AGENTS.md`.
The installer registers Paper Search, and you can select the Papers folder
from Codex after setup.
